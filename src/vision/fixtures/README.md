# Технический пример экспорта
Реальный выход YOLO11n + ByteTrack + OSNet на **искусственных** роликах из повторяющегося публичного bus.jpg. Два источника используют один кадр; это не два реальных ракурса и не проверка межкамерной точности. Файл предназначен для проверки чтения Observation v1 агентами 2 и 3. Здесь только первое наблюдение локального l1 каждого источника; длина embedding 512, L2. Факт одинаковых изображений нельзя использовать как эталон реального MTMC.
Источник: https://github.com/ultralytics/ultralytics/blob/main/ultralytics/assets/bus.jpg .
