# Полный локальный интерфейс CV Office

Запуск: `office_editor.command` из корня проекта, либо `.venv/bin/python -m src.app --open`.
Первичная установка на Mac с Python 3.13: `setup.command`. Основная пользовательская инструкция находится в корневом README, сценарий независимого теста — `docs/manual_test.md`.

## Состав

- `server.py`: loopback HTTP API и статические страницы; браузер не получает произвольного доступа к файловой системе.
- `jobs.py`, `worker.py`: последовательные фоновые запуски в отдельных процессах, снимок настроек, журнал, статус, остановка и восстановление списка результатов после перезапуска UI.
- `project_runtime.py`: перевод графической настройки в контракт Camera v1; проверка видео и связей.
- `geometry.py`: четыре пары конечных неколлинеарных точек, homography pixel -> floor и проверка горизонта. При импорте матрица пересчитывается из исходных точек.
- `fusion.py`: объединение одновременных позиций одного ID с весами confidence², отказ от усреднения при конфликте, сброс сглаживания на пропусках.
- `review_data.py`: дискретные JPEG-превью, окончательные рамки/ID, проекции на плоскость, траектории, CSV и данные просмотра.
- `static/`: два экрана без внешних веб-зависимостей: настройка и просмотр/запуск.

## Координаты и время

План измеряется в метрах, начало слева сверху, x вправо/y вниз. Исходный кадр — пиксели. Положение человека берётся по нижнему центру рамки. Привязка предполагает неподвижную камеру, постоянный зум и плоский пол; коррекция дисторсии пока отсутствует.

`timestamp_s = frame_index / source_fps + time_offset_s`. Последовательный режим расставляет начало по фактической длительности файлов и заданной паузе. Он не превращает последовательные записи в настоящую одновременную съёмку. Общие зоны задаются симметрично; переходы направленно; геометрический сектор автоматически не подтверждает связи.

Предпросмотр по умолчанию 10 FPS, без звука. Для него сохраняются уменьшенные JPEG с реальными индексами исходных кадров, согласованными с `frame_stride`. Анализ по умолчанию выполняется на всех кадрах. Просмотр всех камер подчинён одному времени, с дискретностью предпросмотра. Объединение координат допускает только близкие по времени наблюдения в этом дискретном представлении; пропущенные позиции не дорисовываются.

При расхождении источников больше `fusion_distance_m` результат имеет `status=disagreement`, `x_m=y_m=null`; исходные оценки сохранены. Сглаживание сбрасывается после паузы >0.5 с или конфликта. Секторы и высота остаются схематической настройкой и не заменяют homography. Если привязки нет, графический путь по камерам всё равно доступен.

## Файлы

`configs/office.local.json` — текущая схема; `runs/app/uploads/` — локальные загрузки. Запуск `runs/product/<id>/` содержит:

- `project.json`, `cameras.json`, `job.json`, `status.json`, `worker.log`;
- `vision/observations.jsonl`, `vision/tracklets.json`, `vision/run.json`;
- `association/assignments.jsonl`, `tracks.json`, `reconciliation.json`;
- `frames/`, `review.json`, `tracks.csv`, `positions.csv`, `report.md`, `performance.json`.

Исходные контракты v1 не изменены. `review.json` — производный формат для UI: снимок проекта, камеры/кадры с окончательными рамками, итоговые треки и пути по global ID. Геометрия запуска неизменна после его создания: после изменения привязки нужно выполнить новый запуск. Проект можно экспортировать/импортировать в JSON; видео при переносе нужно сохранить по тем же относительным путям или выбрать заново.

Сервер запускается только на 127.0.0.1. `--project` и `--runs` позволяют изолировать QA от пользовательского проекта. Одновременно выполняется одна обработка. Штатный выход останавливает собственные дочерние процессы. Страница может быть перезагружена без потери выполняющейся задачи; аварийное завершение сервера требует нового запуска. Данные/веса/результаты игнорируются Git.

## Проверка

```sh
.venv/bin/python -m pytest src/app/tests src/vision/tests src/association/tests -q
```

48 тестов, включая известную перспективу, конфликт источников, сброс сглаживания, соответствие кадров/ID, CSV, сохранение, отмену, ограничения жизненного цикла и неоднозначность ReID. CI запускает модульные проверки без скачивания ML-весов. Полный инференс проверен отдельно на первых реальных роликах команды; UI проверен в браузере (запуск, отмена, повторный запуск, восстановление, просмотр/перемотка, выбор трека, графический путь и экспорт).

Это базовый продукт с умеренной точностью, не гарантия безошибочного разделения людей. Весь pipeline офлайн; уточнение ID использует будущие кадры. Полная независимая оценка точности ожидает нового ручного теста. Лицензии моделей и готовых компонентов перечислены в `src/vision/THIRD_PARTY.md`.
