Временная шкала

Для одновременной съёмки задайте одинаковое начало. В геометрическом режиме общие зоны определяются по размеченному полу. Для слепых переходов задайте связи камер. Для последовательных роликов одного телефона можно расставить смещения автоматически.

Разрешённый пол и исключения

Поставьте минимум 3 вершины на кадре и завершите полигон. Проверяется середина нижней стороны рамки. Красные исключения действуют по этой же точке. Настройки сохраняются вместе с камерой и применяются в режиме «Зоны пола + фильтр помех + постсклейка».

Та же точка на плане

Масштаб: + / − или колесо. Сдвиг: Alt + перетаскивание. Номера на кадре и плане обозначают одну физическую точку пола.

Сетка пола и контрольные точки

Отметьте точку №1 на полу в кадре, затем её же на плане справа. Добавляйте пары по всей видимой области пола. Для сетки используйте в том числе промежуточные точки вдоль коридора. Нажмите строку пары, чтобы исправить её. Лучше выбрать углы плитки или другие заметные ориентиры по всей рабочей зоне.
