# Агент 2: межкамерное сопоставление и глобальные ID

Модуль реализует собственную детерминированную логику association поверх контракта
`schema_version = 1` из `docs/contracts.md`. Общий контракт не изменён.

## Что реализовано

- фильтрация кандидатов по времени и топологии камер;
- разные правила для `overlap_with` и направленного `transition_to`;
- cosine-сопоставление только признаков одной модели и одной размерности;
- галерея до пяти наиболее качественных embedding вместо безусловного усреднения кадров;
- консервативный отказ от неоднозначного совпадения;
- единый ID при одновременном наблюдении в перекрывающихся камерах;
- запрет appearance-склейки разных локальных треков одной камеры;
- состояния `active`, `pending`, `closed`, настраиваемый timeout (по умолчанию 10 с);
- восстановление на границе timeout включительно и новый ID после границы;
- окончание трека по времени последнего наблюдения;
- `end_of_video`, `timeout` и опциональный `explicit_exit` как причины закрытия;
- атомарный и воспроизводимый экспорт `assignments.jsonl` и `tracks.json`.

## Входы и выходы

Входы:

- JSON конфигурации камер: `Camera` из общего контракта;
- JSONL наблюдений: `Observation` из общего контракта;
- опциональный JSONL подтверждённых событий выхода (расширение модуля, см. ниже).

Выходы:

- `assignments.jsonl`: ссылка на наблюдение, `global_track_id`, `match_score`, `reason`;
- `tracks.json`: итоговый список `GlobalTrack`.

Embedding должен сопровождаться `embedding_model_id`. Признаки разных моделей или размерностей
не сравниваются. `timestamp_s` уже должен быть временем от общего начала видео; модуль не применяет
`time_offset_s` второй раз.

## Быстрый запуск

Из корня репозитория:

```bash
source .venv/bin/activate
python -m src.association \
  --cameras examples/cameras.json \
  --observations examples/observations.jsonl \
  --output-dir runs/association-baseline \
  --allow-topology-only-baseline
```

В примерах репозитория embedding отсутствуют, поэтому команда выше явно включает baseline.
Для реального экспорта с embedding флаг `--allow-topology-only-baseline` не нужен:

```bash
python -m src.association \
  --cameras path/to/cameras.json \
  --observations path/to/observations.jsonl \
  --output-dir runs/association
```

Параметры:

- `--timeout-s 10.0` - ожидание по `last_seen` всего глобального трека;
- `--similarity-threshold 0.75` - стартовый технический порог, не требование организаторов;
- `--ambiguity-margin 0.05` - минимальный отрыв лучшего кандидата от второго;
- `--min-embedding-confidence 0.50` - минимальная confidence наблюдения для галереи;
- `--gallery-size 5` - число лучших embedding глобального трека.

Порог 0.75 требует настройки на реальном эталоне и проверочном дубле. Его нельзя считать
проходным баллом хакатона.

## Явный выход

Источник события выхода командой пока не согласован, поэтому этот вход выключен по умолчанию.
После согласования можно передать `--exits file.jsonl`. Строка имеет вид:

```json
{"schema_version":1,"camera_id":"cam01","local_track_id":"l1","timestamp_s":7.2}
```

Событие означает подтверждённый выход **глобального** трека из всех ракурсов, а не простой выход
из одной камеры. Оно закрывает трек с `end_s = last_seen_s`. Неизвестная локальная ссылка считается
ошибкой входа.

## Baseline без embedding

Без признаков новый локальный трек по умолчанию всегда получает новый global ID. Явный флаг
baseline разрешает склейку только когда после временной и топологической фильтрации остаётся ровно
один кандидат. При неоднозначности создаётся новый ID. Поле `reason` получает значение
`overlap_topology_baseline` или `transition_topology_baseline`, чтобы результат нельзя было принять
за ReID.

## Установка и проверки

```bash
source .venv/bin/activate
python -m pip install -r src/association/requirements-dev.txt
python -m pytest src/association/tests
python -m ruff check src/association
python scripts/check_examples.py
```

Runtime-зависимостей нет: алгоритм использует стандартную библиотеку Python 3.10+. Для разработки
зафиксированы `pytest==9.2.0` и `ruff==0.17.4`; оба проекта распространяются по лицензии MIT.

## Известные ограничения

- До получения реальных embedding и видео качество ReID подтверждено только синтетическими
  тестами; реальный экспорт агента 1 всё ещё нужен.
- `overlap_with` трактуется симметрично, `transition_to` - направленно.
- Appearance не склеивает разные локальные ID одной камеры. Это консервативно защищает от ложной
  склейки, но не чинит фрагментацию локального трекера внутри одной камеры.
- При отсутствии согласованного события выхода timeout может сохранить ID человеку, который вышел
  и вернулся менее чем через 10 секунд. Это известное отклонение от строгого правила ТЗ.
- Галерея использует `detection_confidence` как доступный показатель качества. После расширения
  контракта агентом 1 можно подключить отдельную оценку качества/окклюзии.
