# Переносимый снимок рабочего офиса

Комплект содержит пять записей камер хакатона, обрезанных до первых 180 секунд без перекодирования, ранние короткие записи команды, оба изображения плана, все JSON-конфигурации и пресеты, PDF постановки, веса YOLO11n и OSNet с provenance, а также последний готовый результат `20261107-205603-b5eb494b` с кадрами, детекциями, признаками, назначениями ID и экспортом.

Старые эксперименты не включены по выбору пользователя. Ссылки на исходные запуски внутри метаданных оставлены как происхождение результата; сами эти исторические запуски отсутствуют. Готовый просмотр и повторное сопоставление работают по включенному кешу последнего результата.

`manifest.json` перечисляет относительные пути, размеры и SHA256 всех файлов и частей архива. Части `assets.tar.gz.part-*` образуют один gzip/tar-поток; каждая меньше 45 МиБ. Git LFS не нужен. Скрипт восстановления использует стандартную библиотеку Python, проверяет контрольные суммы, не допускает символьных ссылок и выхода за корень и не заменяет существующие файлы.

После клонирования запустить `setup.command` (нужен Python 3.13). Он установит зависимости, восстановит данные и запустит приложение. Если окружение уже подготовлено, достаточно `office_editor.command` или:

```sh
.venv/bin/python -m src.app --open
```

Восстановление автоматически выполняется перед запуском сервера. Ручное восстановление без установки ML-зависимостей:

```sh
python3 -m src.demo_bundle
```

Проверка точного соответствия восстановленных файлов снимку:

```sh
python3 -m src.demo_bundle --verify
```

Последняя команда сообщает и об осознанных локальных изменениях: она предназначена прежде всего для проверки чистого клона. Обычный запуск сохраняет локальные настройки и более длинные оригинальные видео на ноутбуке. Окружение `.venv` в коммит не входит: оно зависит от компьютера и создается установщиком.

После запуска открыть `/review?run=20261107-205603-b5eb494b`. В редакторе будут сохраненная схема, камеры, 53 пары точек, маски, масштаб, граф и 12 направленных порталов. Готовый результат содержит 26 подтвержденных эпизодов и 3 кандидата; эти числа не являются метрикой точности.

Укороченные видео сохраняют относительные пути исходников, поэтому хешированные ID ресурсов остаются действительными на другом компьютере. Их разрешение и декодированные кадры сохранены; аудиодорожки не включены. Конечная граничная рамка около 180 с может давать длительность до 180.05 с. `video_metadata.json` отражает укороченные записи; `source_manifest.json` описывает исходные загрузки. Снимки завершенного запуска остаются неизменными.

Для обновления снимка нужно заново сформировать весь архив и manifest из согласованных данных. Простое редактирование игнорируемых рабочих файлов не меняет содержимое архива. Не удалять отдельные части: они необходимы для восстановления.
