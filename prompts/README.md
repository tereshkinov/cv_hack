# Промпты команды

Актуальный этап — тюнинг от `baseline-floor-v1`:

1. [Агент 1 — балансировка оценок и интеграция](tuning/01_scoring.md), ветка `tuning/scoring`.
2. [Агент 2 — геометрия и перемещения](tuning/02_geolocation.md), ветка `tuning/geolocation`.
3. [Агент 3 — осветление и внешность](tuning/03_appearance.md), ветка `tuning/appearance`.

Каждый файл — самостоятельный промпт для передачи агенту. Агент 1 объединяет свидетельства и интегрирует изменения; агент 2 поставляет геометрические признаки; агент 3 — визуальные. Общее сравнение: одинаковые данные, ложные склейки и разрывы, скорость, проверка на отложенных эпизодах. Число ID не заменяет оценку точности.

Старые `01_vision.md`, `02_association.md`, `03_app.md` относятся к созданию первоначального прототипа. Их распределение ролей и ранние настройки не относятся к текущему этапу.
