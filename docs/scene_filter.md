# Зоны пола и фильтр неподвижных помех

В просмотре выберите «Зоны пола + фильтр помех + постсклейка» → «Проверить фрагменты». Используются готовые детекции. Для сравнения без фильтра выберите «Геометрия + постсклейка коротких треков», сохранив те же параметры и разметку. Обычные режимы обработки остаются доступны; фильтр включается отдельным экспериментальным профилем. CLI: --filter-scene в геометрическом режиме.

## Зоны

В настройках камеры появился блок «Разрешённый пол и исключения»:

- Внутри сетки пола: объединение размеченных треугольников кадра. Для старой привязки по четырём точкам — выпуклая оболочка опорных точек.
- Нарисованный полигон: произвольная простая, в том числе невыпуклая, граница. Минимум 3 вершины на кадре → «Завершить полигон».
- Без ограничения: ограничение пола отключено; явно нарисованные исключения продолжают действовать.
- Исключения: отдельные полигоны для экранов/зеркал/других нежелательных участков. Проверяется попадание середины нижней стороны рамки, а не пересечение всего тела с полигоном.

Неполная сетка становится неполной разрешённой зоной: реальные люди за её пределами также будут скрыты. Можно расширить разметку, нарисовать отдельный разрешённый полигон или выключить ограничение для этой камеры. При отсутствии калибровки режим сетки пропускает наблюдения и сообщает камеру в unavailable_zone_cameras; существующие исключения действуют.

Для уже наблюдаемого локального трека есть допуск 1 секунда с момента последней точки строго внутри и 1.5% диагонали кадра (минимум 3 px) за границей. Новое появление снаружи не допускается. Допуск не продлевается внешними точками; исключения не имеют допуска. Это защита границы локального трека, а не предположение об идентичности всех близких людей.

Зоны хранятся в camera.floor_filter вместе с проектом/пресетом. Точки задаются в пикселях исходного кадра. Смена видео сбрасывает эти зоны; изменение кадра времени их не меняет. Невалидные и самопересекающиеся полигоны сервер отклоняет. Калибровочные пары не меняются при рисовании зон.

## Неподвижные вспышки

Применяются после геометрического сопоставления и постсклейки. Эпизоды длиннее 3 секунд и подтверждённые геометрическим объединением нескольких камер защищены. Одиночная детекция без трёх наблюдений не объявляется неподвижной помехой; она остаётся обычным неподтверждённым кандидатом.

Неподвижность: 90-й процентиль отклонения центра ≤ max(3 px, 8% ширины рамки), относительное изменение размеров ≤ 10%. В счёт входят только эпизоды до 3 секунд с минимум тремя наблюдениями. Мерцание — внутренний разрыв более max(0.5 с, 2.5 × медианный шаг наблюдений).

Эвристический балл, **не калиброванная вероятность**:

| Свидетельство | Балл |
|---|---:|
| Исходное значение | 0.10 |
| Неподвижная рамка | 0.20 |
| Короткий эпизод | 0.10 |
| Ещё ≥2 раздельных коротких неподвижных эпизода в том же месте, с похожим размером | 0.30 |
| Средняя уверенность детектора <0.45 | 0.20 |
| Мерцание | 0.20 |

Порог 0.75; дополнительно обязательны слабая уверенность или мерцание. Одиночный уверенный человек, который стоит две секунды, сохраняется. Даже повторные уверенные непрерывные появления не скрываются только за неподвижность. Пороги экспериментальные: для выбора цены пропуска человека относительно ложного срабатывания нужна ручная разметка, пока её нет.

## Проверка

«Показать отфильтрованные» отображает скрытые рамки и строки с причиной. Они исключены из обычного счётчика и проекции пути, но сохранены в assignments/tracks и CSV. Отфильтрованные внешние наблюдения получают filteredN — диагностические ID, а не сквозные идентичности. Исходные observations.jsonl неизменны. Подавленный кандидат неподвижной помехи сохраняет свой прежний ID.

reconciliation.json → scene_filter содержит количество внешних наблюдений и stationary_decisions: центр, дрожание, изменение размеров, уверенность, повторные эпизоды, балл и решение. scene_state / scene_reason сохраняются в назначениях и экспортируются в просмотр. Для контроля входных данных проверяется равенство всех ссылок camera_id/frame_index/local_track_id до и после фильтра.

Первый запуск: 20261107-153226-b206beea. С текущей сеткой 700 из 2272 наблюдений оказались снаружи; 1572 допущены. Внутри осталось 28 подтверждённых эпизодов и 1 кандидат. Дополнительных подавлений по неподвижности — 0: имеющиеся данные не набрали достаточных свидетельств. Уменьшение счётчика не является измерением точности.
