# Постсклейка коротких треков

В просмотре выберите «Геометрия + постсклейка коротких треков» и нажмите «Проверить фрагменты». Нейросети не запускаются повторно. Профиль «Геометрия + внешность при неопределённости» служит контролем без постсклейки. Оба запуска должны использовать одну разметку и параметры.

Обрабатываются отдельные сквозные эпизоды длительностью до 3 секунд. Опора должна иметь не менее 8 секунд наблюдаемого покрытия (пробелы и одновременные камеры не удваивают длительность). Опоры фиксируются перед проходом и не сливаются друг с другом. Новые присоединения не создают новые опоры.

Используется журнал геометрических рёбер основного графа. Все короткие фрагменты эпизода должны иметь прямую поддержку. При вставке между фрагментами опоры нужны обе границы, при одновременном наблюдении проверяются все доступные рёбра. Сохраняются запреты графа: две независимые фигуры одной камеры, физические противоречия, явные выходы. Простой достижимости или неразрешённой неоднозначности недостаточно.

Порог для эксперимента: max(0.58, tracklet_threshold − 0.03), отрыв от следующей альтернативы и варианта «оставить отдельно»: max(0.025, ambiguity_margin). Это оценка совместимости, не калиброванная вероятность. Внешность участвует только через выбранную основную геометрическую политику.

Предложения сортируются по оценке; несовместимые присоединения отклоняются. Это жадный выбор с фиксированными опорами, не глобальный оптимум. Слабые и неоднозначные появления сохраняются отдельно. Подтверждение кандидатов пересчитывается после постсклейки.

Аудит: association/fragment_graph.json → short_stitch.decisions. Содержит исходный ID, альтернативы, оценку, решение и причину. В assignments.jsonl сохраняется pre_stitch_global_track_id, в tracks.json — stitched_from. Исходные наблюдения и старые запуски не меняются.

CLI: добавьте --stitch-short-tracks к геометрическому режиму. По умолчанию функция выключена; в интерфейсе она включается отдельным профилем.
