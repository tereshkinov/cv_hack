# Предлагаемый контракт v1

[Предложение] Три модуля: vision - кадры, детекции, локальные треки и признаки; association - межкамерные связи, глобальные ID и завершение; app - воспроизведение, траектории, счётчик и экспорт.
Ниже - предлагаемый стартовый контракт, а не условие организаторов. Все участники должны подтвердить его до независимой реализации. Изменения фиксируются в docs/contracts.md и согласуются с потребителями.
Общее: schema_version = 1; время в секундах от общего начала видео; frame_index с нуля; bbox = [x1,y1,x2,y2] в пикселях исходного кадра, начало координат сверху слева. Нормализация и размер embedding описываются производителем; признаки разных моделей не сравнивать.
Camera: camera_id, video_path, width, height, fps, time_offset_s, overlap_with, transition_to. Обе связи независимы. Координаты и зоны плана опциональны; неизвестные значения не заменять выдуманными.
Observation: camera_id, frame_index, timestamp_s, local_track_id, bbox_xyxy, detection_confidence; embedding и embedding_model_id опциональны на промежуточном этапе. Без признаков разрешён только явно обозначенный базовый вариант алгоритма.
Association: ссылка на наблюдение (camera_id, frame_index, local_track_id), global_track_id; необязательные match_score и reason. До финального экспорта офлайн-алгоритм может пересмотреть предварительные связи.
GlobalTrack: global_track_id, start_s, last_seen_s, end_s, status, camera_ids, close_reason. В окончательном экспорте все треки завершены либо отмечены end_of_video.
[Предложение] JSON для конфигурации камер и итоговых треков, JSONL для наблюдений и назначений. Пути относительные корню проекта. Примеры находятся в examples/; они синтетические и не являются результатом обработки видео.
Счётчик демо строится по окончательным глобальным ID. Число активных треков и накопленное число треков подписываются отдельно, если показываются оба показателя.

Примеры: examples/cameras.json, observations.jsonl, assignments.jsonl, tracks.json. Перед интеграцией участники подтверждают этот контракт. Проверка scripts/check_examples.py проверяет только примеры, не качество алгоритма.
