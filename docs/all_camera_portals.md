# Зоны переходов для всего графа камер

Сохраненная конфигурация: `configs/presets/office-all-transfers-20261107.json`. В рабочем `configs/office.local.json` активны те же 12 направленных порталов для всех 6 пар существующего графа. Предфинальный пресет не изменен.

| Пара | Стороны перехода на изображениях | Максимальный разрыв |
|---|---|---|
| 1 ↔ 2 | правая передняя часть cam01 / средняя задняя часть cam02 | 4 с |
| 1 ↔ 3 | левая часть cam01 / правый край cam03 | 4 с |
| 2 ↔ 3 | правая часть cam02 / правый край cam03 | 4 с |
| 3 ↔ 4 | дальняя часть коридора cam03 / правый край cam04 | 7 с |
| 3 ↔ 5 | дальняя часть коридора cam03 / дальний конец cam05 | 8 с |
| 4 ↔ 5 | левый край cam04 / дальний конец cam05 | 5 с |

Полигоны и направления выбраны по неподвижным ракурсам, графу офиса и граничным наблюдениям. У 1–2, 1–3 и 2–3 просмотрены примеры в начале/конце ролика. Связи коридоров 3–4 и 3–5 и обратные направления остаются предварительными: топологическое соответствие не доказывает личность конкретного человека. В поле `source` каждого портала записано происхождение, в `provisional` — статус настройки. Ближняя левая дверь cam05 не считается входом в cam03: это отдельная зона ухода в помещение.

Зоны не заменяют общую геометрию: при продолжительном одновременном обзоре сохраняется прежнее сопоставление по полу/траектории. Портал работает на границе фрагментов и только при попадании в оба полигона, допустимом времени и согласованных направлениях движения. На общих ракурсах допускается небольшое перекрытие по времени. При конкуренции используются прежние ограничения графа и внешность.

Для новых порталов требуется не менее 0.6 с наблюдаемого движения с каждой стороны (`min_motion_span_s`). Это не дает повышать уверенность по единичному короткому фрагменту. У прежних 4–5 сохранено исходное значение по умолчанию 0.4 с. Валидатор разрешает 0.4–1.5 с; окно оценки движения составляет 1.5 с.

- Все поля рабочего проекта, кроме `handoff_portals`, сохранены без изменения: ручные пары, сетки, маски, масштаб, временные смещения и обработка. Детекции не пересчитывались.
- 257 тестов прошли; Ruff и git diff --check прошли. Новая регрессия проверяет минимальную длительность движения и валидацию настройки.

Оранжевые зоны и переключатели видны в редакторе при выборе камеры. Точные вершины пока редактируются в JSON; интерфейс рисования масок пола не редактирует порталы. Фон и видео остаются локальными ресурсами; ID в пресете относятся к существующему каталогу.
