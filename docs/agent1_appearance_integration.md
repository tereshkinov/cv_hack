# Агент 1: проверка обработки внешности

Объединена tuning/appearance, коммит eaabf67; merge e109658 в tuning/scoring. Используются геометрия eaglem и наша балансировка; main не менялся.

## Материал и контроль

Источник — runs/product/20261107-100047-e7b28217: 2272 наблюдения первых 180 секунд каждой камеры, из них 816 с признаками внешности. Сохранены рамки, время, confidence, локальные ID, набор допустимых кропов, проект, граф, геометрия и параметры ассоциации. YOLO и ByteTrack повторно не запускались. Для признаков декодированы 702 исходных кадра. Проверка запуска просмотра запрещает подмену детекций и смешение моделей.

Исходные изображения, gamma 0.8 / dark_luma 80 и combined сравниваются отдельно. У gamma отдельный embedding_model_id, 512 компонент; combined — другой ID и 1024 компоненты. Цвет одежды сохранён для анализа и НЕ используется для назначения ID. Его наличие не означает, что в алгоритм добавлены цветовые веса.

Контроль raw полностью совпадает с прежними observations.jsonl побайтно и даёт то же разбиение ID. Исходные результаты не перезаписаны. Новые запуски содержат отдельную vision-метаинформацию: старые tracklets и покамерные embedding-файлы не копируются как новые результаты. JPEG предпросмотра переиспользуются.

## Результат

| Признаки | Треков | Запуск |
|---|---:|---|
| raw | 56 | 20261107-101333-appearance-raw-e6b93b0f |
| gamma | 57 | 20261107-101340-appearance-gamma-c258ade3 |
| combined | 57 | 20261107-101346-appearance-combined-dbfd1735 |

Полный эксперимент признаков занял 74.25 с: OSNet raw 30.57 с, gamma 30.31 с; combined собирается из уже посчитанных векторов. При обычном применении combined требует оба прохода модели. Признак цвета доступен для 586 кропов из 816.

Оба новых режима разделяют одну связь, которую raw объединяет: cam03 / l99 / 163.8–165.2 с → cam01 / l9 / 178.2–179.8 с. В raw оба фрагмента g50; в gamma это g49 и g66. Требуется ручная проверка одного человека/разных людей. Изменения отношений между наблюдениями: 63 пары разделены, новых объединений нет; это не число ошибок и не метрика точности.

Подтверждённого прироста качества нет: человеческая разметка отсутствует, IDF1/HOTA не измерены, независимого отложенного теста нет. Режим off остаётся исходным. Gamma по умолчанию не включена. Подготовлены review_pairs.jsonl (неподтверждённые кандидаты для разметки), CSV различий и отдельные просмотры.

## Воспроизведение

```sh
.venv/bin/python -m src.vision.appearance_experiment --cameras runs/product/20261107-100047-e7b28217/cameras.json --observations runs/product/20261107-100047-e7b28217/vision/observations.jsonl --output runs/appearance/NEW-EXPERIMENT --color --device cpu
.venv/bin/python -m scripts.appearance_preview --source runs/product/20261107-100047-e7b28217 --experiment runs/appearance/NEW-EXPERIMENT
```

Эксперимент требует новый каталог. Для прежних правил решений добавить ко второй команде --decision-mode baseline. Сравнение артефактов: scripts/compare_scoring.py с --allow-appearance-change разрешает различие только embedding/embedding_model_id, сохраняя прежние проверки детекций, проекта, камер, параметров и набора наблюдений с признаками.

96 тестов прошли. Новые проверки импорта запрещают изменённые рамки, исчезнувшие признаки и смешение пространств моделей до создания результатов. Проверены реальные веса OSNet и все три варианта на офисных кропах. Ruff для новых модулей и интеграции, git diff --check проходят.
