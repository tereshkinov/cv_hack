# Проверка демонстрации
- [ ] Два синхронных видео и проверенное общее начало времени.
- [ ] Один человек одновременно в общей зоне - один ID.
- [ ] Переход между камерами - тот же ID.
- [ ] Разные люди, в том числе похожая одежда, не склеены.
- [ ] Пропуск меньше 10 с и восстановление при подтверждённом совпадении.
- [ ] Пропуск ровно 10 с; пропуск больше 10 с - отдельные граничные сценарии.
- [ ] После закрытия новый ID, даже если вернулся тот же человек.
- [ ] Счётчик соответствует списку окончательных треков.
- [ ] Графическая траектория в отдельном окне, формат согласован.
- [ ] Повторный запуск даёт тот же результат.
- [ ] Есть пример ошибки и объяснение ограничения тайм-аута.
- [ ] Список библиотек/моделей, версии, лицензии и инструкция.
