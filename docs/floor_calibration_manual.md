# Привязка пола: ручная проверка

1. Откройте http://127.0.0.1:8765/ и выберите «Камера 1».
2. Выберите неподвижный кадр с хорошо видимым полом. Подложка office.jpg уже выбрана.
3. Укажите четыре пары: точка пола на кадре, затем та же физическая точка на плане справа. Выбирайте широко разнесённые ориентиры; не используйте столы и стены.
4. Масштабируйте кнопками +/− или колесом, сдвигайте с Alt. Для исправления нажмите строку нужной пары, затем укажите новое положение на нужной стороне.
5. Привязка рассчитывается автоматически. В режиме «Проверить кликом» отметьте другую точку пола: зелёная отметка должна попасть в ожидаемое место плана.
6. Повторите для остальных камер. Проверьте сохранение после перезагрузки.
7. Откройте «Просмотр и запуск», выберите завершённый трёхминутный результат и нажмите «Обновить проекцию готовых треков».
8. Выберите ID. На плане появятся его наблюдаемые участки пути. ID при перепроекции не меняются; нейросети не запускаются.

Калибровки реальных камер намеренно не заполнены автоматически. Технические проверки выполнялись в отдельном проекте runs/floor-qa и не являются разметкой офиса.

Масштаб сейчас условный; физические скорости и расстояния в метрах не определяются. Искажение широкоугольных камер может давать ошибки вне размеченной области.

Для изменения ID после настройки пола используйте «Пересчитать ID по привязке пола». Кнопка «Обновить проекцию готовых треков» сохраняет ID. Обе создают отдельный результат без повторного запуска нейросетей.
