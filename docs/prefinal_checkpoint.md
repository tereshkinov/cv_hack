# Предфинальная версия — 2026-11-07

Сохраненная конфигурация: `configs/presets/office-prefinal-20261107.json`.
Это точная копия рабочей конфигурации на момент сохранения: схема, ручные привязки, сетки пола, граф камер, временные смещения, масштаб, порталы 4–5 и текущие параметры обработки. Исходные видео, фон плана и результаты обработки остаются в локальной `data/` и `runs/`, в Git не включены. Идентификаторы ресурсов относятся к текущему локальному каталогу; на другом компьютере необходимо заново подключить соответствующие видео и план.

Восстановление при остановленном сервере (предварительно сохранить свою текущую конфигурацию):

```sh
cp configs/office.local.json configs/presets/before-prefinal-restore.local.json
cp configs/presets/office-prefinal-20261107.json configs/office.local.json
```

После этого запустить обычный редактор/просмотр. Для рабочего проекта по-прежнему используется `configs/office.local.json`; редактор автоматически сохраняет последующие правки туда.

Проверенный прогон: `20261107-165700-be992ced`. Его точные параметры сохранены внутри `runs/product/20261107-165700-be992ced/project.json`; настройки рабочего редактора могли изменяться после запуска. В предфинальный пресет сохранены именно актуальные настройки редактора, без их сброса к параметрам прогона.

Состав версии: фильтрация вне размеченного пола, подавление шумных коротких эпизодов, постобработка коротких фрагментов, геометрические переходы по траекториям, обработка пограничных кадров и порталы переходов между камерами. Подробности — `scene_filter.md`, `short_track_stitching.md`, `trajectory_handoffs.md`, `boundary_handoff_fix.md`, `cam45_transfer_fix.md`.

Ограничения: отсутствие эталонной разметки не позволяет оценить общую точность; обратный портал 5→4 требует ручной проверки. Порталы сохраняют ID при расхождении калибровок, но не устраняют скачок координат на схеме.
