# Локальный эксперимент: линковка между камерами

## Ограничения эксперимента

- Работа выполнена только локально в ветке `tuning/local-camera-linking`.
- Использованы первые 180 секунд пяти `camera_new_*.mkv`, каждый пятый исходный кадр.
- Нейросетевые детекции и OSNet-признаки сохранены в локальном запуске `20261107-104047-7c33a92f` и повторно использованы для сравнения.
- Ручного полного эталона ID нет, поэтому количество треков не называется IDF1, HOTA или точностью.
- Привязки пола для камер ещё не заданы; геометрия нейтральна.

## Найденная причина разрыва

Offline-reconcile принимал направленный переход только при строгом условии `source.end < target.start`. На реальных записях ByteTrack и небольшая ошибка синхронизации создают короткое формальное перекрытие соседних tracklet'ов. Даже хорошее многокадровое ReID-сходство в такой ситуации вообще не рассматривалось.

Добавлен отдельный параметр `transition_overlap_tolerance_s`, по умолчанию `0.75 с`. Он применяется только к явно заданному направленному ребру графа камер и только в offline-reconcile. Симметричное перекрытие камер, ограничения одной камеры, timeout, ambiguity margin и пороги внешности не ослаблены. Длинное перекрытие остаётся недопустимым переходом.

## Результат на одинаковых наблюдениях

| Вариант | Итоговых треков | ID на 2+ камерах | Offline-слияний |
|---|---:|---:|---:|
| Строгий baseline | 65 | 5 | 8 |
| Допуск 0.75 с | 64 | 6 | 9 |

Восстановлена конкретная визуально правдоподобная цепочка человека в чёрной футболке: `cam4/l6` → `cam3/l51` → `cam3/l73`. Ранее первый и последующие фрагменты имели разные ID; после изменения они входят в один `g22`. Снижение глобальных порогов не использовалось.

Медиана трёх локальных пересчётов на 2272 наблюдениях: 3.4779 с для строгого варианта и 4.2448 с с допуском. Дополнительная проверка кандидатов увеличила время примерно на 0.77 с; повторный детектор и чтение видео не требуются.

Число 64 само по себе не доказывает рост точности. Нужна ручная проверка восстановленного эпизода и соседних кандидатов в интерфейсе. Новый локальный результат: `20261107-105231-1c5d3a78`.

## Дополнительные наблюдения

- На `cam3` детектор часто принимает людей на экране/телевизоре за реальных людей. Это создаёт лишние локальные треки и неоднозначные кандидаты; association не может надёжно исправить ошибку детектора без информации о запрещённой области.
- Короткие и сильно обрезанные фрагменты имеют 1–2 пригодных ReID-кадра. Автоматическое снижение минимального числа образцов увеличит риск ложных склеек, поэтому оно не включено.
- В текущем примере некоторые разные люди в тёмной одежде получают высокое OSNet-сходство. Поэтому глобально снижать `tracklet_threshold` ниже 0.62 небезопасно.
- Без четырёх точек пола на камеру пространственное противоречие не может остановить внешне похожую, но физически невозможную склейку.

## Следующие улучшения по приоритету

1. Разметить пол всех камер и проверить независимые контрольные точки. Это даст сильный способ отвергать физически невозможные совпадения.
2. Добавить на кадрах ignore-зоны для телевизоров, зеркал и неподвижных рекламных изображений; для `cam3` это наиболее заметный источник ложных людей.
3. Задать для каждого направленного ребра минимальное/максимальное время перехода и отдельные входные/выходные зоны кадра.
4. Оценить постоянные временные смещения камер по нескольким вручную подтверждённым переходам, а не увеличивать общий допуск.
5. Проверить гибридный дескриптор OSNet + HSV-цвет одежды. Цвет должен быть вторичным сигналом, поскольку баланс белого камер отличается.
6. Разметить 15–30 переходов и конкурирующих похожих людей, разделить их на tuning/holdout и считать IDF1/HOTA, ложные склейки и разрывы отдельно.

## Воспроизведение

```sh
.venv/bin/python -m src.association \
  --cameras runs/test-stand/20261107-104047-7c33a92f/cameras.json \
  --observations runs/test-stand/20261107-104047-7c33a92f/vision/observations.jsonl \
  --output-dir runs/experiments/camera-linking-tolerance \
  --project runs/test-stand/20261107-104047-7c33a92f/project.json \
  --timeout-s 15 --similarity-threshold 0.72 \
  --tracklet-threshold 0.62 --ambiguity-margin 0.03 \
  --adjacency-bonus 0.04 --transition-overlap-tolerance-s 0.75
```
